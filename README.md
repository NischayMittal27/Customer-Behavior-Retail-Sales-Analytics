# Customer Behavior & Retail Sales Analytics

An end-to-end data analytics project analyzing 3,900 customer records to uncover patterns in customer behavior, purchasing, revenue, subscriptions, product performance, and shipping preferences.

The project follows a complete analytics workflow:

**Python & Pandas → Data Cleaning & Feature Engineering → PostgreSQL → SQL Analysis → Power BI Dashboard**

---

## Overview

This project analyzes retail customer and transaction data to understand:

- Customer purchasing behavior
- Revenue contribution by gender and age group
- Subscription and repeat-purchase patterns
- Product ratings and discount behavior
- Shipping preferences and spending
- Customer segmentation
- Product performance across categories

The analysis combines Python-based data preparation, PostgreSQL data storage, SQL-based analysis, and an interactive BI dashboard.

---

## Dataset

The original dataset contains:

- **3,900 customer records**
- **18 columns**
- Customer ages ranging from **18–70**
- Purchase amounts ranging from **$20–$100**
- Data covering **50 locations**
- **4 seasons**
- **37 missing Review Rating values**

After data cleaning:

- **15 columns** remained
- Missing review ratings were imputed using category-level median values
- A numerical `purchase_frequency_days` feature was created
- An `age_group` feature was created
- A redundant column was removed

The cleaned dataset was loaded into PostgreSQL for SQL analysis.

## Project Workflow

### 1. Data Loading & Exploration

The raw CSV dataset was loaded and profiled using Python and Pandas.

The dataset was examined for:

- Duplicate/redundant columns

---

### 2. Data Cleaning & Feature Engineering

The dataset was cleaned and prepared for analysis.

Key transformations included:

- Handling **37 missing Review Rating values**
- Imputing missing ratings using category-level medians
- Converting purchase frequency categories into numerical day values
- Creating customer `age_group` segments
- Removing a redundant column
- Reducing the dataset from **18 to 15 columns**

---

### 3. PostgreSQL Data Loading

The cleaned dataset was loaded into PostgreSQL using:

- SQLAlchemy
- psycopg2

The resulting customer table was then used for SQL-based analysis.

## SQL Analysis

The project contains SQL queries designed to answer key business questions.

### Key Questions Answered

**1. Revenue by Gender**

Compared total revenue generated by male and female customers.

**2. Discounted Purchases Above Average**

Identified customers who used discounts while spending at or above the overall average purchase amount.

**3. Top-Rated Products**

Identified the top 5 products based on average review rating.

**4. Shipping & Average Spend**

Compared average purchase amounts between Standard and Express shipping.

**5. Subscription & Spending**

Compared subscribers and non-subscribers using:

- Customer count
- Average spending
- Total revenue

**6. Discount Rate by Product**

Identified the 5 products with the highest percentage of purchases made using discounts.

**7. Customer Segmentation**

Segmented customers into:

- New
- Returning
- Loyal

based on previous purchase count.

**8. Top Products by Category**

Used SQL window functions to identify the top 3 most-purchased products within each category.

**9. Repeat Buyers & Subscription**

Analyzed subscription status among customers with more than 5 previous purchases.

**10. Revenue by Age Group**

Compared total revenue contribution across customer age groups.

## Key Results

The analysis identified several notable patterns:

- **3,900** customers analyzed
- Approximately **$233K** in total revenue
- **$59.76** average purchase amount
- **3,116** customers classified as Loyal
- Loyal customers represented approximately **79.9%** of the customer base
- Male customers contributed approximately **67.7%** of total revenue
- Subscribers had a **91.0% repeat-buyer rate**, compared with **88.4%** for non-subscribers
- Express-shipping customers had an average purchase amount of **$60.48**, compared with **$58.46** for Standard shipping
- Revenue across age groups was relatively evenly distributed
